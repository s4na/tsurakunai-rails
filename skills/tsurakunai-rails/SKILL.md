# つらくないRails

既存の呼び出し名を維持する入口です。依頼に合うスキルを読み、そちらの手順で進めてください。

- 作成・修正・リファクタリング: [実装スキル](../tsurakunai-rails-implement/SKILL.md)。一つの利用者操作から、責務・失敗処理・テストを組み立てる
- レビュー・問題の調査: [レビュースキル](../tsurakunai-rails-review/SKILL.md)。必須条件の欠落・禁止形・期待する状態を壊す経路を読み取り専用で確認する

両方とも[チーム規約](references/team-policy.md)のT01〜T09を参照し、「満たすべき形」と「許さない形」の両方で実装・合否を拘束します。先に導入先のRAILS_TEAM_POLICY.mdと明示規約を確認し、同じ仕事の書き方を揃えます。実装依頼の最後に自分で確認することと、別担当による独立レビューは区別してください。依頼範囲や外部操作の権限を増やしません。
