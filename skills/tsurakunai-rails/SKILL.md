# つらくないRails

既存の呼び出し名を維持する入口です。依頼に合うスキルを読み、そちらの手順で進めてください。

- 作成・修正・リファクタリング: [実装スキル](../tsurakunai-rails-implement/SKILL.md)。一つの利用者操作から、責務・失敗処理・テストを組み立てる
- レビュー・問題の調査: [レビュースキル](../tsurakunai-rails-review/SKILL.md)。期待する状態を壊す具体的な経路を読み取り専用で確認する

両方とも[共通の設計判断](references/daily-design.md)を参照します。実装依頼の最後に自分で確認することと、別担当による独立レビューは区別してください。依頼範囲や外部操作の権限を増やしません。
